# Scoliosis5K

Scoliosis5K contains 4,998 corridor-walking recordings from 3,010 participants. Each recording pairs RGB video, silhouettes and 25 two-dimensional pose landmarks.

[Project website](https://zizhaopeng.github.io/Scoliosis5K-site/) · [Model code](https://github.com/ZizhaoPeng/Scoliosis5K-code) · [Apply for dataset access](https://zizhaopeng.github.io/Scoliosis5K-site/#access) · [Preprint](https://arxiv.org/abs/2611.26849v1)
